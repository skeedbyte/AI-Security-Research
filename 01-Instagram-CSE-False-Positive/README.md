# Case Study 01: Instagram AI - False Positive Pattern (CSE)

**Status:** Student research | Public reports only
**Date:** Oct 2026
**Goal:** Learn AI Integrity & Trust

### Observed Pattern
Public reports from creators describe accounts disabled for Child Sexual Exploitation while posting non-violating content (family, dance, fully clothed).

### User Impact
- Loss of account & appeals not working
- Loss of trust in AI moderation
- High emotional cost

### My Hypothesis as a Student
Automated detection may be over-weighting visual signals without enough context (caption, account history, age of subjects) and routing low-confidence cases to auto-disable instead of human review.

### Improvement Ideas
1. Confidence thresholding -> low confidence = human review queue
2. Context layer -> caption + history + relationship graph
3. Better appeal queue -> fast-track likely false positives for manual check

This is part of my learning journey from Cisco NetAcad (Prompt Injection) to AI Security & Integrity.
